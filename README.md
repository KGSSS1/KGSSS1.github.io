# KrovIPO

Predicts an Indian IPO's listing price from grey market premium (GMP), subscription and market mood.
Live at https://kgsss1.github.io/KrovIPO/ and packaged as an Android app (Trusted Web Activity).

This repo holds only the built web app. It is generated by `make_calculator.py` in the ipo-model project; don't edit `index.html` by hand.

A statistical estimate from past IPOs, not investment advice.
